# Player Profile Specification

## Core Profile

Planned fields include:
- profile photo
- first name
- last name
- display name
- province
- city/town
- bio
- social links
- preferred play style
- dominant hand
- preferred position

Only collect fields that have product value and a privacy justification.

## Profile Management

Players can:
- edit profile,
- change profile photo,
- manage social links,
- manage notification preferences,
- manage privacy settings,
- manage club memberships.

## Profile Screens

Web/mobile:
- Profile
- Edit Profile
- Settings
- Notifications

## Privacy

Separate public profile fields from private account settings.

Never return sensitive account information in a public player endpoint.

## OAuth

OAuth connections are managed independently from the public player profile.
